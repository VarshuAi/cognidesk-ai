## 🚀 Quickstart & Usage

### 1. Clone the Repository
```bash
git clone https://github.com/VarshuAi/cognidesk-ai.git
cd cognidesk-ai
```

### 2. Execution
Open `index.html` directly in your browser or run with a local static server:
```bash
npx serve . -p 3000
```
