# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within CogniDesk AI, please send an email to `gowdavarshan466@gmail.com` or open a private advisory on GitHub.

Please include:
- Description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and suggested mitigations.

We will review and respond promptly.
